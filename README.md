# 🚗 Lexcar

Учёт заправок, расхода топлива и обслуживания Toyota Prius+ 1.8 HSD (2012).
React + recharts, все данные хранятся в `localStorage` браузера — сервер не нужен.

## Возможности

| Вкладка | Что внутри |
|---|---|
| 🏠 Главная | текущий пробег, средний расход и цена, суммы по топливу и ТО, прогресс до замены масла, ближайшие задачи, 3 последние заправки, карточка автомобиля |
| ⛽ Топливо | добавление и правка заправки со скидками и автоподсчётом расхода л/100 км, список всех заправок, удаление с пересчётом |
| 📊 Графики | расход (со средним), цена €/л, помесячная сводка с таблицей |
| 🔧 История ТО | добавление и правка работ, фильтр по 8 категориям, цветовая маркировка, сводка расходов |
| 🔔 Задачи | просроченные, запланированные, ожидают установки, информация, выполненные; создание, правка, удаление; красный бейдж считает только невыполненные просроченные |

Кнопка ☰ в шапке открывает боковое меню: карточка автомобиля с актуальным
пробегом, разделы приложения, страница «Автомобиль» (фото, основные данные,
покупка, паспорт, масло, трансмиссия, охлаждающие жидкости, шины, номера
деталей, документы — с редактированием) и экран «Данные и настройки».

Лупа в шапке открывает глобальный поиск по всем данным: заправкам, записям
ТО, задачам и полям профиля автомобиля. Поиск локальный, без учёта регистра
и диакритики, по частичным совпадениям; нажатие на результат открывает
нужную запись или секцию.

Три темы — 🌙 тёмная, ☀️ светлая, 📖 сепия — выбираются в «Данных и настройках»
и запоминаются между запусками.

## Локальный запуск

```bash
npm install
npm start
```

## Хранение данных

| Ключ localStorage | Что хранит |
|---|---|
| `autocontrol_fuel` | заправки |
| `autocontrol_service` | записи ТО |
| `autocontrol_reminders` | задачи и напоминания |
| `autocontrol_theme` | выбранная тема |
| `autocontrol_vehicle` | технические данные автомобиля (паспорт, жидкости, шины, покупка, документы) |

Фото автомобиля хранится отдельно — в IndexedDB (`lexcar` → `photos`), перед
сохранением уменьшается до 1600 px по большей стороне и пережимается в JPEG.
В резервную копию оно не входит.

При первом запуске подставляются данные из [`src/data.js`](src/data.js).
Чтобы вернуться к ним, очистите ключи `autocontrol_*` в localStorage.

### Как считается расход

Расход заправки = литры ÷ пробег от предыдущего **полного** бака × 100.
Заправка без отметки «Полный бак» собственного расхода не получает — её литры
переносятся в следующую полную заправку и не участвуют в средних значениях
и графиках. После изменения или удаления заправки расход всех последующих
топливных циклов пересчитывается автоматически; более ранние записи сохраняют
исторические значения.

### Стоимость и скидки

| Поле | Смысл |
|---|---|
| `grossTotal` | стоимость топлива до скидки (литры × цена) |
| `discount` | скидка на кассе |
| `paidTotal` | реально оплаченная сумма |

Финансовая статистика («Топливо всего», расходы по месяцам) считается по
`paidTotal`, средняя цена — по `pricePerL`, объём — по `liters`. Скидка никогда
не уменьшает количество литров. Записи старого формата (одно поле `total`)
подхватываются автоматически: `grossTotal = paidTotal = total`, `discount = 0`.

### Резервная копия

Экран «Данные и настройки» (нижний пункт бокового меню): экспорт всех данных
в JSON (`version`, `exportDate`, `fuel`, `service`, `reminders`, `vehicle`,
`theme`), импорт из файла с предупреждением, проверкой структуры и
подтверждением перед заменой, а также двухэтапная очистка всех данных.

## Деплой на Cloudflare Pages (основной)

Проект `lexcar` в Cloudflare Pages подключён к репозиторию GitHub: каждый
push в `main` автоматически собирается и публикуется.

- Build command: `npm run build`
- Build output directory: `build`
- Framework preset: Create React App

Приложение работает от корня домена (`/`), поэтому `homepage` в `package.json`
не задаётся. Файл `public/_redirects` (`/* /index.html 200`) отдаёт SPA на
любой адрес.

## Резервный деплой на GitHub Pages

Старый адрес `https://adar4026.github.io/prius-tracker/` оставлен как резервный.
`npm run deploy` собирает проект с префиксом `PUBLIC_URL=/prius-tracker` и
заливает его в ветку `gh-pages`.


1. Создайте пустой репозиторий на GitHub (например `prius-tracker`).

2. Впишите свой путь в скрипт `predeploy` в `package.json`
   (`PUBLIC_URL=/имя-репозитория`).

3. Свяжите папку с репозиторием и запушьте:

   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/prius-tracker.git
   git branch -M main
   git push -u origin main
   ```

4. Соберите и опубликуйте:

   ```bash
   npm run deploy
   ```

   Команда сама выполнит `npm run build` и зальёт папку `build` в ветку `gh-pages`.

5. В настройках репозитория **Settings → Pages** выберите
   Source: *Deploy from a branch*, ветку `gh-pages`, папку `/ (root)`.

6. Через минуту сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/имя-репозитория/`.
   Каждое следующее обновление — снова `npm run deploy`.

## Установка на iPhone

Откройте адрес в Safari → «Поделиться» → **«На экран «Домой»»**.
Приложение запустится в полноэкранном режиме со своей иконкой 🚗
(manifest и apple-touch-icon уже настроены).

> Данные привязаны к браузеру конкретного устройства и не синхронизируются
> между телефоном и компьютером.
