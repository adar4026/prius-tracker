# 🚗 Autocontrol

Учёт заправок, расхода топлива и обслуживания Toyota Prius+ 1.8 HSD (2012).
React + recharts, все данные хранятся в `localStorage` браузера — сервер не нужен.

## Возможности

| Вкладка | Что внутри |
|---|---|
| 🏠 Главная | текущий пробег, средний расход и цена, суммы по топливу и ТО, прогресс до замены масла, ближайшие задачи, 3 последние заправки, паспорт авто |
| ⛽ Топливо | добавление заправки с автоподсчётом расхода л/100 км, список всех заправок, удаление |
| 📊 Графики | расход (со средним), цена €/л, помесячная сводка с таблицей |
| 🔧 История ТО | добавление работ, фильтр по 8 категориям, цветовая маркировка, сводка расходов |
| 🔔 Задачи | просроченные, запланированные, ожидают установки, информация; красный бейдж в навигации |

Три темы — 🌙 тёмная, ☀️ светлая, 📖 сепия — переключаются кнопкой в шапке
и запоминаются между запусками.

## Локальный запуск

```bash
npm install
npm start
```

## Хранение данных

| Ключ localStorage | Что хранит |
|---|---|
| `autocontrol_fuel` | заправки |
| `autocontrol_service` | записи ТО |
| `autocontrol_reminders` | задачи и напоминания |
| `autocontrol_theme` | выбранная тема |

При первом запуске подставляются данные из [`src/data.js`](src/data.js).
Чтобы вернуться к ним, очистите ключи `autocontrol_*` в localStorage.

### Как считается расход

Расход новой заправки = литры ÷ пробег от предыдущего **полного** бака × 100.
Заправка, отмеченная «Не до полного», собственный расход не получает — её литры
переносятся в следующую полную заправку и не участвуют в средних значениях
и графиках.

## Деплой на GitHub Pages

1. Создайте пустой репозиторий на GitHub (например `prius-tracker`).

2. Впишите свой логин в `package.json` — поле `homepage` должно совпадать
   с адресом Pages:

   ```json
   "homepage": "https://ВАШ_ЛОГИН.github.io/prius-tracker"
   ```

3. Свяжите папку с репозиторием и запушьте:

   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/prius-tracker.git
   git branch -M main
   git push -u origin main
   ```

4. Соберите и опубликуйте:

   ```bash
   npm run deploy
   ```

   Команда сама выполнит `npm run build` и зальёт папку `build` в ветку `gh-pages`.

5. В настройках репозитория **Settings → Pages** выберите
   Source: *Deploy from a branch*, ветку `gh-pages`, папку `/ (root)`.

6. Через минуту сайт будет доступен по адресу из `homepage`.
   Каждое следующее обновление — снова `npm run deploy`.

## Установка на iPhone

Откройте адрес в Safari → «Поделиться» → **«На экран «Домой»»**.
Приложение запустится в полноэкранном режиме со своей иконкой 🚗
(manifest и apple-touch-icon уже настроены).

> Данные привязаны к браузеру конкретного устройства и не синхронизируются
> между телефоном и компьютером.
